主打项目

Evo-FinAgent

基于 LangGraph 与 Harness 治理的企业级金融投研 Multi-Agent 系统

输入一个美股 ticker，四个节点（数据采集 → 财务分析 → 风险抽取 → 报告撰写）协同产出一份带估值分析和风险提示的投研报告，全程 可审计、可断点续跑、带人工审核卡点。

财务数字直接取自 SEC XBRL 官方申报，不经过 LLM 推算； 风险因素逐条附原文依据，可回溯核验；执行摘要里出现的每一个 数字都会经过溯源校验，查不到出处就会被标记为潜在幻觉。
